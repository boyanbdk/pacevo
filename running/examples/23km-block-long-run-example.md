# 23km Block Long Run Example

## Original Workout

- Session 1: 8.5 km at conversational pace.
- Session 2: 6.5 km at 4:55/km.
- Session 3: 8 km at conversational pace.
- No walking rests.

## User Inputs

- Treadmill mode: distance-based.
- Easy/warm-up pace: 6:20/km.
- Cool-down pace: 6:40/km.
- Rest walking pace: skipped, no walking rests.
- Feeling: 6/10.
- Desired push: normal.

## Adjustment Logic

This is a long run, not an interval session, so the structure stays controlled and distance-based. Feeling 6/10 with normal push keeps the prescribed 4:55/km block unchanged and uses separate easy and cooldown paces for the conversational sections.

## Adjusted Treadmill Workout

| Step | Treadmill instruction | Notes |
| --- | --- | --- |
| Block 1 | 9.5 km/h (6:20/km) until 8.5 km | Easy opening block |
| Block 2 | 12.2 km/h (4:55/km) until 6.5 km | Prescribed steady block |
| Block 3 | 9.0 km/h (6:40/km) until 8.0 km | Cooldown/conversational finish |
